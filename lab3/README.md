# ЛР 3 · Меню без стандартных виджетов и сравнение по KLM

Вариант 1 лабораторной работы по проектированию человеко-машинного интерфейса — **переименование файла**. В ЛР 2 задача решена командным языком и меню на стандартных виджетах. Здесь — третье, альтернативное решение в парадигме меню **без стандартных виджетов**: окно в стиле Norton Commander, в котором программа сама рисует строку меню, выпадающие меню, список файлов, строку функциональных клавиш, поля ввода и диалоговые окна. Из библиотеки Tkinter взяты только окно и холст (Canvas) как поверхность для рисования.

Все три решения сравнены по методике KLM в отчёте `Отчёт_ЛР3_ЧМИ_ГОСТ.docx`.

## Запуск

Нужен Python 3.10+ и Windows, устанавливать ничего не надо.

```bash
cd lab3
python make_demo.py        # создать тестовый каталог demo или вернуть его в исходное состояние
python nc_menu.py demo     # программа
python -m unittest test_fileops
```

## Клавиши

| Клавиша | Действие |
| --- | --- |
| ↑ ↓, PgUp, PgDn, Home, End | перемещение курсора по списку |
| Enter | войти в каталог; на файле — переименовать его |
| Backspace | на уровень выше |
| Insert, пробел | отметить файл или снять отметку |
| Ctrl+A | отметить все файлы |
| Esc | снять отметку; в окне — закрыть окно |
| F1 | справка |
| F2 | переименовать файл под курсором |
| F3 | переименовать отмеченные файлы: текст в начало, текст в конец, новое расширение |
| F4 | отметить файлы по маске (`*` — любые символы, `?` — один символ) |
| F5 | обновить |
| F6 | перейти в каталог по пути (относительному или абсолютному) |
| F7 | сменить сортировку: по имени, по размеру, по дате |
| F9 | меню: стрелки, Enter, Esc, выделенные буквы |
| F10 | выход |

Мышь тоже работает: щелчок по строке, двойной щелчок, правая кнопка отмечает файл, щелчок по строке меню, по F-клавишам внизу и по кнопкам окон, колесо прокручивает список.
