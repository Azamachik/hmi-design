# ЛР 2 · Парадигмы интерфейса: командный язык и меню

Вариант 1 лабораторной работы по проектированию человеко-машинного интерфейса — **переименование файла**. Одна и та же задача (управление файловым каталогом) решена в двух парадигмах: консольная программа с командным языком и оконная программа с меню. Обе работают в текущем каталоге, показывают его содержимое, переименовывают один файл или группу файлов и меняют текущий каталог.

Стек: Python 3.10+ и стандартная библиотека (окно — на виджетах Tkinter). Устанавливать ничего не нужно. Программы рассчитаны на Windows.

## Запуск

```bash
python make_demo.py        # создать тестовый каталог demo
python shell.py demo       # командный язык
python menu.py demo        # меню
python -m unittest test_fileops
```

Каталог можно не указывать — тогда программа начнёт работу в том каталоге, из которого запущена.

## Командный язык

| Команда | Синтаксис |
| --- | --- |
| Список каталога | `dir [маска]` — с маской показывает, что под неё подходит |
| Смена каталога | `cd [путь]` — путь относительный или абсолютный |
| Переименовать один файл | `ren <имя> <новое-имя>` |
| Переименовать группу файлов | `ren <маска> <новая-маска>` |
| Справка | `help [команда]` |
| Выход | `exit` |

В маске `*` — любое число любых символов, `?` — ровно один символ. В новой маске каждый знак `*` и `?` заменяется тем, что совпало с таким же по счёту знаком исходной маски:

```
ren заметки.txt записи.txt
ren *.txt *.md                        смена расширения
ren IMG_*.jpg отпуск_*.jpg            замена начала имени
ren * старое_*                        приставка ко всем файлам
ren отчёт_?.docx отчёт_2026_?.docx
```

Имена с пробелами берутся в кавычки, регистр букв не учитывается. Группа переименовывается целиком или не переименовывается вовсе: сначала проверяются все новые имена, и если хотя бы одно занято или недопустимо, не меняется ни один файл. Каталоги команда `ren` не трогает.

| Ситуация | Сообщение |
| --- | --- |
| Неизвестная команда | `Неизвестная команда: <глагол>. Введите help.` |
| Файла нет | `Файл не найден: <имя>` |
| Каталога нет | `Каталог не найден: <путь>` |
| Ничего не подошло под маску | `Нет файлов, соответствующих маске: <маска>` |
| Целевое имя уже занято | `Файл с именем <новое-имя> уже существует. Переименование отменено.` |

## Меню

- **Файл** — открыть каталог, вверх, обновить, выход.
- **Правка** — переименовать файл (F2), переименовать группу (Ctrl+R), выделить всё, выделить по маске (Ctrl+F), снять выделение.
- **Вид** — столбцы «Размер» и «Изменён», подменю «Сортировка».
- **Справка** — как пользоваться, о программе.

Те же действия есть в контекстном меню списка и на панели кнопок. Группа выделяется мышью с Ctrl или Shift либо по маске. В окне переименования группы выбирается действие — добавить текст в начало имени, добавить в конец или сменить расширение — и сразу виден предпросмотр новых имён. Недоступные сейчас пункты меню затенены.
